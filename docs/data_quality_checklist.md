# Data Quality Checklist

- [ ] Observation period defined
- [ ] Licence and permitted use confirmed
- [ ] Missing values checked
- [ ] Duplicate transactions checked
- [ ] Invalid or inconsistent dates checked
- [ ] Inconsistent category names standardised
- [ ] Unusual order amounts reviewed
- [ ] Duplicate customer identifiers checked
- [ ] No post-prediction-date information used as a predictor (leakage)
- [ ] Sample bias and small groups reviewed
- [ ] Exclusions and transformations documented
